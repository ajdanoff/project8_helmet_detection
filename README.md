# Helmet Detection: детекция работников без защитного шлема

Проект посвящён разработке модели компьютерного зрения для автоматического обнаружения нарушений техники безопасности на промышленных объектах, стройках и складах. Модель детектирует людей на изображениях и определяет, носят ли они защитный шлем.

**Цель:** построить пайплайн от автоматической разметки данных до обучения и оценки модели детекции, способной находить работников без шлема.

## Бизнес-контекст

На промышленных предприятиях и строительных площадках одно из ключевых правил техники безопасности — обязательное ношение защитного шлема. Нарушение этого правила повышает риск травм, инцидентов, простоев и штрафов.

Ручной контроль по видеопотоку трудоёмок и дорог. Автоматические системы на базе компьютерного зрения позволяют:

- в реальном времени обнаруживать сотрудников без шлема;
- фиксировать нарушения и формировать отчёты;
- снижать количество инцидентов и издержки.

В этом проекте вы построите модель для такой системы.

## Описание проекта

Проект состоит из двух основных этапов:

1. **Генерация разметки с помощью VQA-модели.**
   - Исходный датасет содержит только изображения людей в шлемах и без.
   - С помощью мультимодальной VQA-модели (Qwen2.5-VL) и фреймворка vLLM генерируется автоматическая разметка:
     - bounding box для каждого человека;
     - метка класса: `with_helmet` / `without_helmet`.
   - Разметка приводится к формату YOLO.

2. **Обучение модели детекции.**
   - На сгенерированном датасете обучается детектор YOLOv8.
   - Оценивается качество по метрикам mAP@0.5, mAP@0.5:0.95, precision, recall.
   - Анализируются типичные ошибки и предлагаются пути улучшения.

Весь пайплайн (предобработка, аннотация, обучение, оценка) воспроизводится через один Jupyter-ноутбук.

## Быстрый старт

1. **Скачать датасет**

```bash
mkdir -p data/raw
cd data/raw

wget -O images.zip \
  "[https://code.s3.yandex.net/deep-learning-cv/images.zip?etag=c508a8c704db94187fe6e0b8219479e9-4](https://code.s3.yandex.net/deep-learning-cv/images.zip?etag=c508a8c704db94187fe6e0b8219479e9-4)"

unzip -q images.zip
cd ../..
```

2. **Запустить vLLM сервер**

```bash
vllm serve "Qwen/Qwen2.5-VL-7B-Instruct-AWQ" \
  --trust-remote-code \
  --dtype float16 \
  --quantization awq \
  --max-model-len 4096 \
  --limit-mm-per-prompt '{"image": 1}' \
  --enforce-eager \
  --gpu-memory-utilization 0.85 \
  --port 8000
```

3. **Открыть ноутбук**

```bash
jupyter notebook project_notebook.ipynb
```

4. **Выполнить ячейки по порядку:**
   - загрузка и визуализация данных;
   - генерация VQA-разметки;
   - конвертация в YOLO-формат;
   - обучение модели;
   - оценка и анализ ошибок.

## Этап 1: генерация разметки

### Датасет

- 1001 изображение с рабочими в шлемах и без.
- Разрешение ~416×416 пикселей.
- Изображения загружаются без видимых проблем.

### VQA-модель

- Модель: **Qwen/Qwen2.5-VL-7B-Instruct-AWQ**
- Запуск через vLLM с квантованием AWQ для экономии памяти.
- Строгий JSON-промпт для генерации bounding box и меток классов.

### Результаты генерации

```text
total: 1001
processed: 1001
images_with_detections: 907
total_detections: 3168
empty_or_failed: 94
```

- 907 изображений (90.6%) содержат хотя бы одну детекцию.
- 94 изображения (9.4%) без детекций (пустые кадры или пропущенные люди).
- В среднем ~3.5 детекции на изображение с людьми.

### Особенности разметки

- Классы `with_helmet` / `without_helmet` определяются хорошо.
- Наблюдается систематическое **смещение bbox вниз**, особенно для удалённых объектов.
- Для близких объектов рамка может немного «съезжать» вниз, но в целом покрывает человека.

На основе этой псевдоразметки формируется датасет в YOLO-формате (801 train / 200 val).

---

## Этап 2: обучение модели

### Конфигурация

- Модель: **YOLOv8s** (`yolov8s.pt`), ~11.1M параметров.
- Датасет: 801 train / 200 val изображений, 2 класса.
- Разрешение: `imgsz=640`, batch=16, epochs=50.
- Оптимизатор: AdamW, AMP включён.
- GPU: Tesla T4 (16 ГБ).

### Метрики на валидации

```text
                  Class     Images  Instances      Box(P          R      mAP50  mAP50-95)
                    all        200        606      0.53      0.467      0.419      0.183
          with_helmet        158        439      0.516      0.569      0.496      0.214
       without_helmet         53        167      0.545      0.365      0.341      0.151
```

Ключевые показатели:

- **mAP@0.5:** 0.419
- **mAP@0.5:0.95:** 0.183
- **Precision:** 0.53
- **Recall:** 0.467

Модель лучше детектирует людей в шлемах (`with_helmet`), чем без шлемов (`without_helmet`), что связано с дисбалансом классов и качеством псевдоразметки.

### Типичные ошибки

- **Смещение bbox вниз** на удалённых объектах (рамка покрывает преимущественно нижнюю часть туловища).
- **Пропуск людей с лёгкой окклюзией** (за сеткой, лесами, конструкциями).
- **Хуже детекция `without_helmet`**:
  - часть людей без шлемов не детектируется;
  - часть ошибочно классифицируется как `with_helmet`.

Несмотря на это, модель демонстрирует устойчивую сходимость и способность решать задачу на базовом уровне.

## Пути улучшения

Для повышения качества детекции рекомендуется:

1. **Улучшение данных:**
   - ручная коррекция 100–200 наиболее проблемных аннотаций;
   - целенаправленное дополнение класса `without_helmet`;
   - использование более агрессивных аугментаций (mosaic, mixup, scale).

2. **Улучшение модели:**
   - переход на YOLOv8m/l;
   - обучение с большим разрешением (`imgsz=1280`);
   - увеличение числа эпох и тонкая настройка гиперпараметров.

3. **Расширение датасета:**
   - дообучение на публичных PPE-датасетах (Safety-Helmet-Wearing-Dataset, Roboflow Construction-PPE);
   - использование синтетических данных для усиления minority-класса.

4. **Пост-обработка:**
   - настройка confidence/NMS thresholds;
   - class-specific пороги для повышения recall `without_helmet`.
